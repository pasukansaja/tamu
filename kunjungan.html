📲 Alur Pendaftaran Kunjungan

Tiga langkah, tanpa buku tamu tulis.

  1. Scan QR di meja depan / poster sekolah.
  2. Isi formulir data tamu: nama sesuai KTP, NIK, instansi/lembaga, data Pers/LSM (bila ada), nomor HP, tujuan kunjungan, dan rencana tanggal.
  3. Menunggu persetujuan — permohonan diteruskan ke WhatsApp sekolah dengan status menunggu.
  4. Kode Izin Kunjungan hanya diterbitkan & dikirim ke WhatsApp tamu setelah manajemen sekolah menyetujui.

🏫 Identitas Sekolah & WhatsApp

Nama sekolah muncul di header, formulir, pesan WA, dan poster QR. Nomor WA menjadi tujuan penerima data tamu.

Tanpa tanda + dan tanpa 0 di depan. Contoh: nomor 0812-3456-7890 ditulis 6281234567890.
Pilihan “Lainnya (tulis sendiri)” selalu tersedia otomatis di formulir.

🛡️ Persetujuan Manajemen Sekolah

Kode Izin Kunjungan hanya terbit setelah permohonan disetujui di sini. Menyetujui → kode izin otomatis dibuat dan siap dikirim ke WhatsApp tamu.

🔳 QR Code Kunjungan

🤖 Teks Balasan Otomatis

Muncul langsung di layar tamu (gaya WhatsApp) setelah mendaftar. Variabel: {nama} {kode} {tanggal} {tujuan} {sekolah}

Variabel pesan persetujuan: {nama} {kode} (nomor pendaftaran) {kodeIzin} {tanggal} {tujuan} {sekolah}

📖 Panduan Singkat

    
    
      
  1. Host file ini — unggah ke Netlify Drop / GitHub Pages / server sekolah agar QR bisa discan HP tamu.
    2. 
      
  2. Isi identitas & nomor WA sekolah pada kartu di atas, lalu tekan Simpan.
    3. 
      
  3. Tempel URL aplikasi → QR dibuat otomatis → unduh PNG atau cetak poster QR.
    4. 
      
  4. Alur persetujuan: tamu mendaftar dengan status Menunggu Persetujuan → manajemen menekan Setujui pada kartu Persetujuan Manajemen → Kode Izin Kunjungan otomatis terbit dan siap dikirim ke WhatsApp tamu. Tanpa persetujuan, kode izin tidak diterbitkan.

  5. Balasan otomatis nyata di HP sekolah: aktifkan WhatsApp Business ▸ Alat bisnis ▸ Pesan sambutan, atau hubungkan gateway WhatsApp (Fonnte, Wablas, dll.) untuk balasan bot penuh.

  6. Opsional: pasang webhook Google Sheets agar seluruh permohonan terpusat — tombol Muat Permohonan dari Sheets menarik data ke panel persetujuan, dan tamu bisa mengecek status kapan pun lewat kartu Cek Status Pendaftaran.
